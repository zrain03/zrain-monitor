New here? How monitoring and Telegram alerts work
  1. Add a monitor: Enter a public HTTPS website or API address. Checks run approximately every 5 minutes.
  2. Connect Telegram: Open Account & notifications → Telegram alerts, use the secure bot link and confirm the connection.
  3. Choose a website: Select its name in Active monitors below, then enable Telegram alerts in Monitor details.
  4. Get updates: Confirmed downtime and recovery appear in Event history. Telegram messages are optional and require an enabled monitor.

Need an explanation of UP, VERIFYING, DOWN, UNKNOWN or Keep-Awake? Read the monitoring guide.
